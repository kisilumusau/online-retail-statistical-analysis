# Online Retail Statistical Analysis

## Project Overview

This project analyses the Online Retail dataset using R.

The analysis includes data cleaning, exploratory data analysis,
descriptive statistics, visualisations, and statistical testing.

## Files

- `online_retail_analysis.R` — R script containing the statistical analysis.
- `Online_Retail.xlsx` — dataset used for the analysis.
- `online_retail_statistical_analysis_report.pdf` — written report.

## Analysis

The analysis examines online retail transaction data and compares
sales between UK and non-UK transactions.

The project uses R and packages including:

- readxl
- dplyr
- ggplot2

## How to Run

1. Download or clone this repository.
2. Open `online_retail_analysis.R` in RStudio.
3. Ensure the dataset is located in the `data` folder if the script
   uses the relative data path.
4. Run the script.
